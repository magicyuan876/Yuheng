# 企业版

玉衡的核心——文档解析、检索问答、在线协同文档、知识健康——都在这个仓库里，MIT 协议，这一点不会变。企业版是在社区版之上，面向规模更大的组织加几项可选能力，与一般开源项目的开源核心 + 商业版模式一样：两者共享同一套代码和同一条发布线，企业版不是另起炉灶的独立产品。

## 现在能用到什么

目前企业版还没有发布，下面都是规划中的能力，还不能使用。社区版部署会在「设置 → 企业版」看到对应的说明卡片，点进去不会有任何购买入口——没有的东西不卖。

| 能力 | 说明 |
| --- | --- |
| 权限感知检索 | 条目级别的访问控制：受限的知识只会出现在有权限查看的人的回答里 |
| SAML 单点登录 | 接入企业身份提供方（IdP），并保留本地应急管理员登录，避免身份服务故障时整个系统进不去 |
| 审计日志导出 | 把审计日志导出为文件，或转发到 syslog、Webhook，接入企业已有的 SIEM |
| 更多检索引擎 | 在内置的 PostgreSQL（ParadeDB + pgvector）引擎之外，接入 OpenSearch 等社区版不提供的引擎 |

## 这是怎么接起来的

社区版代码里有一处专门的接缝（`internal/extension`）：一个 `Features` 注册表，核心代码只会问"这个功能开没开"，从不知道、也不关心功能背后是谁实现的。企业版通过一行空白导入把自己挂上去，不改动社区版的任何一行代码。部署的 `GET /api/v1/system/capabilities` 接口会把每个企业版能力的状态上报给前端：未安装企业版时，这些能力既不是"锁定"也不是"启用"，而是干脆不存在——前端据此只显示介绍，不显示任何锁图标或升级弹窗。

感兴趣的可以读[扩展点](../06-development/03-extension-points.md)了解这套接缝的完整设计，或者直接看[开源仓库里 `internal/extension` 的源码](https://github.com/magicyuan876/Yuheng/tree/main/internal/extension)。
