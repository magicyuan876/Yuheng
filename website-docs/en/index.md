# Yuheng documentation

Yuheng is an open-source, LLM-powered knowledge platform. It ingests documents, parses and indexes them, answers questions with citations, and can turn a knowledge base into a Wiki site.

**Chinese is the primary language of this documentation.** Only the two pages below are translated into English. Everything else, including the API reference, the architecture notes and the feature guides, is Chinese.

- [Installation](./01-getting-started/02-installation.md): build and run Yuheng with Docker Compose (the first release publishes no Docker images, so you build them locally), plus Helm and running from source.
- [Quick start](./01-getting-started/03-quickstart.md): register the first account, configure models, upload documents and ask a question, in the UI and with curl.

Yuheng is a 0.x preview: the `/api/v1` REST API may change between 0.x releases, and MCP tool names are stable. The source is at [github.com/magicyuan876/Yuheng](https://github.com/magicyuan876/Yuheng); the [README](https://github.com/magicyuan876/Yuheng/blob/main/README.md) is in English.
