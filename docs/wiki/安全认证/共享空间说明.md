# 共享空间说明

本文档说明 Yuheng 中的**共享空间**功能，包括空间创建与加入、成员角色与权限、知识库共享规则。

## 共享空间概述

共享空间是跨空间协作的载体。用户可以在同一系统内属于不同空间（账户），通过**加入同一共享空间**，实现：

- 共享知识库：将本空间的知识库共享到空间，供空间内其他成员使用
- 访问他人共享的知识库

### 核心概念对照

| 概念 | 说明 |
|------|------|
| 共享空间 | 系统中的「组织」（Organization），用于跨空间共享 |
| 空间创建者 | 自动成为管理员，不可被移除或降级 |
| 空间成员 | 管理员 / 编辑者 / 只读 三种角色 |
| 知识库归属 | 始终属于一个空间；共享不改变归属 |

## 角色与权限

| 能力 | 管理员 | 编辑者 | 只读 |
|------|:-:|:-:|:-:|
| 查看、检索共享知识库 | ✓ | ✓ | ✓ |
| 编辑共享知识库内容 | ✓ | ✓ | ✗ |
| 将知识库共享到本空间 | ✓ | ✓ | ✗ |
| 管理空间设置与成员 | ✓ | ✗ | ✗ |
| 生成/刷新邀请码 | ✓ | ✗ | ✗ |

## 知识库共享规则

- 只有知识库所属空间下的用户才能发起共享
- 发起人必须是目标空间的**管理员**或**编辑者**
- 共享时指定权限：只读或可写
- 同一知识库可共享到多个空间，各自独立配置权限

> 智能体共享已随 Agent 基础设施移除（见迁移 `000089_drop_agent_infra`），共享空间仅支持知识库。
