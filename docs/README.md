# Developer notes

The primary documentation is the VitePress site in [`../website-docs/`](../website-docs/README.md)
(Chinese; the quick start and installation pages also have English versions).
Start there. Per topic, `website-docs/` is the source of truth for: getting
started and installation, architecture, feature descriptions, the REST API
reference (`website-docs/04-api/`), clients and the development guide.

This directory keeps notes that exist only here. They are mostly Chinese.
