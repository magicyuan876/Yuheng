# Developer notes

The documentation lives in the VitePress site in [`../website-docs/`](../website-docs/README.md)
(Chinese; the quick start and installation pages also have English versions).
It covers installation and configuration, architecture, every feature, the
REST API reference (`website-docs/04-api/`), the clients and the development
guide. Start there; a topic that has a page on the site has no second copy here.

This directory keeps only what does not belong on the site:

| File | Topic |
| --- | --- |
| [ROADMAP.md](./ROADMAP.md) | Project direction (a list of intentions, not a schedule) |
| [QA.md](./QA.md) | Frequently asked questions, with links into the site |
| [migration-troubleshooting.md](./migration-troubleshooting.md) | Recovering from a failed or dirty database migration, step by step |
| [cloud-image/](./cloud-image/README.md) | Tencent Lighthouse image packaging (unverified for this release) |

`swagger.json`, `swagger.yaml` and `docs.go` are generated by `make docs`; do
not edit them by hand. The Swagger UI is served at `/swagger/index.html` when
the server does not run in release mode.
