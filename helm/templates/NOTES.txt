  ACCESSING YUHENG
--------------------------------------------------------------------------------

{{- if .Values.ingress.enabled }}

  URL: {{ if .Values.ingress.tls.enabled }}https{{ else }}http{{ end }}://{{ .Values.ingress.host }}

To access Yuheng, use port-forwarding:

  # Frontend (Web UI)
  kubectl port-forward svc/frontend -n {{ .Release.Namespace }} 8080:80

  # Then open: http://localhost:8080

  helm upgrade {{ .Release.Name }} ./helm \
    --set ingress.enabled=true \

--------------------------------------------------------------------------------
  FILE STORAGE
--------------------------------------------------------------------------------
{{- if eq .Values.storage.type "rustfs" }}

Uploaded files are stored in the bundled RustFS, bucket "{{ .Values.storage.s3.bucket }}" under
"{{ .Values.storage.s3.pathPrefix }}", on {{ if .Values.storage.rustfs.persistence.enabled }}the PVC {{ .Values.storage.rustfs.persistence.existingClaim | default (printf "%s-rustfs" (include "yuheng.fullname" .)) }} ({{ .Values.storage.rustfs.persistence.size }}){{ else }}an emptyDir: they are LOST whenever the RustFS pod is replaced{{ end }}.
The app creates the bucket on its first upload. RustFS is a single server
with no redundancy of its own; back up its volume like the database's.

  # RustFS console (sign in with secrets.storageAccessKey / storageSecretKey)
  kubectl port-forward svc/rustfs -n {{ .Release.Namespace }} {{ .Values.storage.rustfs.service.consolePort }}:{{ .Values.storage.rustfs.service.consolePort }}
  # Then open: http://localhost:{{ .Values.storage.rustfs.service.consolePort }}
{{- else if eq .Values.storage.type "s3" }}

Uploaded files are stored in the external object storage
{{ .Values.storage.s3.endpoint | default (printf "AWS S3 (%s)" .Values.storage.s3.region) }}, bucket "{{ .Values.storage.s3.bucket }}" under "{{ .Values.storage.s3.pathPrefix }}".
{{- if and (not .Values.secrets.existingSecret) (not .Values.secrets.storageAccessKey) }}
No access keys are set: the app authenticates through the AWS default
credential chain (for example IRSA via serviceAccount.annotations).
{{- end }}
{{- else }}

Uploaded files are stored on the app's local volume, {{ if .Values.storage.local.persistence.enabled }}the PVC {{ .Values.storage.local.persistence.existingClaim | default (printf "%s-data-files" (include "yuheng.fullname" .)) }} ({{ .Values.storage.local.persistence.size }}){{ else }}an emptyDir: they are LOST whenever the app pod is replaced{{ end }}.
This mode supports one app replica; use storage.type=rustfs or s3 to scale.
{{- end }}

The storage location is recorded on first start. Changing storage.type, the
bucket or a path prefix later makes the app refuse to start while files
exist at the old location: that is a data migration, not an upgrade.

--------------------------------------------------------------------------------
  CONNECTING TO LLM
--------------------------------------------------------------------------------

Yuheng requires an LLM backend. Configure via environment variables:

  helm upgrade {{ .Release.Name }} ./helm \
    --set app.extraEnv[0].name=OLLAMA_BASE_URL \
    --set app.extraEnv[0].value=http://ollama:11434 \
    --set app.extraEnv[1].name=INIT_LLM_MODEL_NAME \
    --set app.extraEnv[1].value=qwen2.5:7b

Supported LLM backends:
  - Ollama (local)
  - OpenAI API compatible endpoints
  - Qwen, DeepSeek, and other Chinese LLMs

{{- if .Values.neo4j.enabled }}

--------------------------------------------------------------------------------
  GRAPHRAG (KNOWLEDGE GRAPH)
--------------------------------------------------------------------------------

Neo4j is enabled for GraphRAG feature.

To use GraphRAG, enable Neo4j. NEO4J_ENABLE is the sole graph switch and is
injected automatically when neo4j.enabled=true (no need to set ENABLE_GRAPH_RAG,
which is deprecated and no longer read by the app):

  helm upgrade {{ .Release.Name }} ./helm \
    --set neo4j.enabled=true \
    --set neo4j.password=<your-secure-password>

Access Neo4j Browser:
  kubectl port-forward svc/neo4j -n {{ .Release.Namespace }} 7474:7474 7687:7687
  # Open: http://localhost:7474

{{- end }}
